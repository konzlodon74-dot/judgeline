## The line

> My plants died of neglect, my sourdough starter died of neglect, and at this point my therapist is just taking notes for the sequel.

## Why it fits

- Single line, single file, Python 3 standard library only.
- The joke escalates in threes: plants, sourdough, therapist — with the punchline landing on the last beat.
- Self-deprecating and relatable without needing any setup or context.
- Writes exactly one UTF-8 line to `/output/entry.txt`, validated before writing.

## How to run

```bash
python3 main.py
cat /output/entry.txt
```
